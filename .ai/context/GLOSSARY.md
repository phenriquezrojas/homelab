# Glossary

| Término | Significado |
| --- | --- |
| ADR | Registro de una decisión arquitectónica duradera. |
| EOS | Engineering Operating System: capa de conocimiento permanente del repositorio. |
| Host | Servidor Ubuntu objetivo que ejecutará la plataforma. |
| Persistencia | Datos que sobreviven a la recreación de contenedores; se ubican bajo `/srv`. |
| Runbook | Procedimiento operativo paso a paso. |
| Sprint | Unidad de trabajo con alcance, estado y salida verificable. |
| Task | Unidad trazable de trabajo dentro de una fase y sprint. |
| Best Effort | Resultado informativo que puede ser incompleto por permisos o herramientas ausentes. |
| DR | Disaster Recovery: capacidad documentada y probada de restaurar datos y operación. |
