# Project Context

Homelab es una plataforma self-hosted personal para preservar patrimonio digital familiar mediante una operación reproducible, recuperable y documentada.

El repositorio concentra las decisiones, procedimientos, configuración declarativa y evidencias de operación. El hardware puede cambiar; los datos y la capacidad de reconstrucción son prioritarios.
