# Skills

Las skills son roles de ingeniería, no prompts ni dependencias de un modelo. Un agente puede asumir uno o más roles, pero debe respetar sus límites y la Constitución.

| Skill | Propósito |
| --- | --- |
| [Architecture](architecture.md) | Proteger coherencia arquitectónica y ADR. |
| [Implementation](implementation.md) | Convertir planes aprobados en cambios acotados y verificables. |
| [Review](review.md) | Detectar riesgos, inconsistencias y deuda antes de aprobar. |
| [Operations](operations.md) | Mantener evidencia operativa, runbooks y recuperación. |
