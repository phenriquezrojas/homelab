# HL-0011 — Diseñar la instalación reproducible de Docker Engine

- **ID:** HL-0011
- **Objetivo:** Definir el procedimiento exacto y reproducible para instalar Docker Engine y Docker Compose Plugin en Ubuntu Server LTS, alineado con ADR-002.
- **Descripción:** Documentar la secuencia de instalación de Docker CE usando el repositorio oficial de Docker (no el paquete de Ubuntu), incluyendo la gestión de claves GPG, el repositorio apt, los paquetes a instalar, y la verificación post-instalación. Todo en forma de contrato de diseño, sin código ejecutable.
- **Dependencias:** HL-0009, HL-0010, ADR-002.
- **Estado:** Planned
- **Responsable:** Unassigned
- **Sprint:** Sprint 1.A
- **Fase:** Phase 1 — Bootstrap
- **ADR:** ADR-002

## Checklist

- [ ] Especificar la URL oficial del repositorio Docker para Ubuntu.
- [ ] Definir los paquetes exactos a instalar: `docker-ce`, `docker-ce-cli`, `containerd.io`, `docker-buildx-plugin`, `docker-compose-plugin`.
- [ ] Documentar la verificación de idempotencia para la instalación de Docker (qué hacer si ya está instalado).
- [ ] Definir el comando de verificación funcional post-instalación (`docker run hello-world`).
- [ ] Documentar el procedimiento de rollback completo para Docker.
- [ ] Definir la versión mínima aceptable de Docker Engine (≥ 24.0) y Docker Compose Plugin (≥ 2.0).

## Notas

Se instala Docker CE desde el repositorio oficial de Docker, no desde el paquete `docker.io` de Ubuntu, porque garantiza versiones más recientes y soporte oficial. Esta decisión está alineada con ADR-002. El plugin `docker-compose-plugin` reemplaza el binario standalone `docker-compose` (v1), en conformidad con las prácticas actuales de Docker.
