# HL-0009 — Diseñar la estructura y contrato del script de bootstrap

- **ID:** HL-0009
- **Objetivo:** Producir el diseño completo del script `bootstrap/bootstrap.sh` como contrato técnico que Sprint 1.B pueda implementar sin tomar nuevas decisiones.
- **Descripción:** Definir el flujo de ejecución, fases, estrategia de idempotencia, logging y rollback del script de bootstrap. No escribir código ejecutable.
- **Dependencias:** Sprint-0.B (HL-0006, HL-0007, HL-0008 completados), ADR-001, ADR-002, ADR-003.
- **Estado:** Planned
- **Responsable:** Unassigned
- **Sprint:** Sprint 1.A
- **Fase:** Phase 1 — Bootstrap
- **ADR:** ADR-001, ADR-002, ADR-003

## Checklist

- [ ] Definir el flujo completo del script en fases numeradas (ahora 0–6).
- [ ] Establecer las condiciones de cada fase: cuándo avanza, cuándo aborta.
- [ ] Documentar el contrato de la función `ensure_directory`: crea si no existe, valida permisos, nunca aborta por existencia previa.
- [ ] Documentar la estrategia de idempotencia (aprobada: principio mixto con tres niveles de funciones).
- [ ] Definir el esquema de logging (formato, destino, niveles `INFO`/`OK`/`WARN`/`ERROR`).
- [ ] Documentar la estrategia de rollback para cada fase.
- [ ] Obtener aprobación explícita del diseño antes de pasar a Sprint 1.B.

## Notas

El diseño se ubica en `Sprint-1-Plan.md`. Esta tarea valida que el contrato es suficientemente claro y aprobado.
