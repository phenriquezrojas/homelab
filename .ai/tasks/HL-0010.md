# HL-0010 — Definir prerrequisitos verificables del host

- **ID:** HL-0010
- **Objetivo:** Especificar con precisión todas las condiciones que el host debe cumplir antes de ejecutar el bootstrap, de forma que puedan ser verificadas automáticamente por el script en FASE 0.
- **Descripción:** Documentar la lista de prerrequisitos del host (SO, usuario, conectividad, repositorio clonado) y el comportamiento esperado del script si alguno falla. La estructura `/srv/homelab` ya no es un prerrequisito externo; el propio bootstrap la garantiza en FASE 1.
- **Dependencias:** HL-0009, ADR-003.
- **Estado:** Planned
- **Responsable:** Unassigned
- **Sprint:** Sprint 1.A
- **Fase:** Phase 1 — Bootstrap
- **ADR:** ADR-003

## Checklist

- [ ] Listar todos los prerrequisitos del host (SO, conectividad, usuario, repositorio).
- [ ] Para cada prerrequisito, definir el comando de verificación exacto.
- [ ] Definir el comportamiento del script si el prerrequisito falla (abort con mensaje específico).
- [ ] Confirmar explícitamente que `/srv/homelab` NO es un prerrequisito externo: su creación y validación es responsabilidad del propio script (FASE 1).
- [ ] Incluir la verificación de versión Ubuntu LTS aceptable.

## Notas

El host actual es Ubuntu en versión LTS. El script debe verificar que `lsb_release -is` retorna `Ubuntu` y que la versión de soporte es LTS activa. A diferencia de diseños previos, la ausencia de `/srv/homelab` ya no es un error: es una condición que el bootstrap corrige automáticamente en FASE 1, haciendo el script completamente reproducible en hosts nuevos.
