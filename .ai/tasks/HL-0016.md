# HL-0016 — Diseñar Docker Compose y Caddyfile para el proxy inverso

- **ID:** HL-0016
- **Objetivo:** Definir la configuración declarativa completa de Caddy como proxy inverso containerizado.
- **Descripción:** Diseñar el `docker-compose.yml` y el `Caddyfile` base que Sprint 2.B implementará. Incluir la red Docker compartida, los volúmenes de persistencia bajo `/srv`, y un endpoint de health check como servicio mínimo de validación.
- **Dependencias:** Sprint 1.B, ADR-002, ADR-007, HL-0015.
- **Estado:** Completed
- **Responsable:** AI Agent
- **Sprint:** Sprint 2.A
- **Fase:** A — Diseño
- **ADR:** ADR-002, ADR-007
