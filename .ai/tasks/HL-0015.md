# HL-0015 — Diseñar instalación idempotente de Tailscale

- **ID:** HL-0015
- **Objetivo:** Definir el procedimiento completo de instalación, autenticación y validación de Tailscale en el host.
- **Descripción:** Documentar cómo instalar Tailscale de forma idempotente (verificar antes de actuar), autenticar el nodo en la tailnet y validar que la conexión esté activa. Incluir la excepción de intervención humana para la primera autenticación.
- **Dependencias:** Sprint 1.B, ADR-006.
- **Estado:** Completed
- **Responsable:** AI Agent
- **Sprint:** Sprint 2.A
- **Fase:** A — Diseño
- **ADR:** ADR-006

## Checklist

- [x] Definir procedimiento de instalación (script oficial de Tailscale).
- [x] Documentar la excepción de intervención humana (primer `tailscale up`).
- [x] Definir verificación de estado (`tailscale status`, `systemctl`).
- [x] Definir procedimiento de reversión.
- [x] Establecer criterios de aceptación para Sprint 2.B.

## Notas

Tailscale se instala directamente en el host (no como contenedor) porque requiere acceso directo al stack de red del kernel para crear y operar la interfaz `tailscale0`. Esta es una excepción documentada al principio Docker First (ADR-002).
